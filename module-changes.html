What happened to the bioinformatics modules?

If you were expecting a Bioinformatics module and an Advanced Bioinformatics module, both remain available under revised names. Each module retains its own content; the name changes do not mean either module has been removed.

Previous nameCurrent name
Bioinformatics, interpretation and data quality assurance in genome analysisGM11 · Variant interpretation
Advanced Bioinformatics — from genomes to systemsGM5 · Bioinformatics, interpretation and data quality assurance in genomic analysis

The Variant interpretation module focuses on clinical variant classification. The Bioinformatics module develops computational skills for analysing and interpreting sequencing data.
